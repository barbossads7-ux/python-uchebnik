## Тема 1. Типы данных

**Переменная** — имя, которое ссылается на значение. Создаётся присваиванием:

```python
name = "Alice"
name = "Boba"   # теперь name ссылается на новое значение
```

Python чувствителен к регистру: `"biba"` и `"Biba"` — разные строки, `name` и `Name` — разные переменные.

Узнать тип: `type(x)`.

### 1.1 Простые типы

| Тип | Что это | Пример |
|---|---|---|
| `str` | строка, всегда в кавычках `""` или `''` | `"Alice in Home"` |
| `int` | целое число | `10`, `-3` |
| `float` | дробное число (через точку!) | `10.0`, `3.14` |
| `bool` | логическое значение | `True`, `False` |
| `NoneType` | «значения нет» | `None` |

`None` — переменная есть, но значения пока нет: `result = None`.

### 1.2 Сложные типы (коллекции)

**Список `list`** — `[ ]`, упорядоченный, изменяемый, может хранить что угодно, в т.ч. другие списки.

```python
fruits = ["Banana", "Apple", 5, 4, [1, 2, 3]]
print(fruits[0])    # Banana — индексы с 0
print(fruits[-1])   # [1, 2, 3] — отрицательный индекс считает с конца
```

**Кортеж `tuple`** — `( )`, как список, но **неизменяемый**. Нужен, когда данные не должны меняться.

```python
car = ("Колёса", "КПП", "Двигатель")
one = ("привет",)   # кортеж из одного элемента — ОБЯЗАТЕЛЬНО запятая
not_tuple = ("привет")  # это просто строка!
```

**Словарь `dict`** — `{ключ: значение}`. Доступ не по индексу, а по ключу.

```python
student = {
    "name": "biba",
    "age": 19,
    "grades": {"Математика": [5, 5, 3], "Русский": [2, 2]},
}
print(student["name"])                    # biba
print(student["grades"]["Математика"])    # [5, 5, 3]
student["city"] = "Orenburg"              # добавили новый ключ
```

**Множество `set`** — `{ }` без пар ключ:значение. Хранит только **уникальные** элементы, порядка нет (индексов нет).

```python
fruits = {"Banana", "Banana", "banana", "apple"}
print(fruits)   # {'Banana', 'banana', 'apple'} — дубль убран
unique = set([1, 1, 2, 3, 3])   # {1, 2, 3} — быстро убрать повторы
empty = set()   # пустое множество; {} — это пустой СЛОВАРЬ
```

### 1.3 Изменяемые и неизменяемые типы

- **Неизменяемые:** `int`, `float`, `str`, `bool`, `tuple`. «Изменить» их нельзя — Python создаёт новый объект (`x = x + 1` даёт новое число).
- **Изменяемые:** `list`, `dict`, `set`. Меняются на месте (`fruits.append(3)`).

Зачем: неизменяемые безопаснее там, где значение должно быть стабильным. Только неизменяемые могут быть ключами словаря и элементами множества.

Подводный камень **[дописано]**:

```python
a = [1, 2, 3]
b = a          # b — это ТОТ ЖЕ список, а не копия
b.append(4)
print(a)       # [1, 2, 3, 4] — изменился и a!
c = a.copy()   # вот это копия
```

### 1.4 Преобразование типов [дописано]

```python
int("25")      # 25
float("3.5")   # 3.5
str(25)        # "25"
list("abc")    # ['a', 'b', 'c']
set([1, 1, 2]) # {1, 2}
bool(0), bool(""), bool([])   # все False; любое непустое/ненулевое — True
int("abc")     # ОШИБКА ValueError
```

### 1.5 Индексы и срезы [дописано]

Работают для `str`, `list`, `tuple`: `x[start:stop:step]`, `stop` не включается.

```python
s = "Python"
s[0]      # 'P'
s[1:4]    # 'yth'
s[:2]     # 'Py'
s[::-1]   # 'nohtyP' — разворот
```

### 1.6 Полезные методы [дописано]

Строки (возвращают новую строку, оригинал не меняют):
`s.lower()`, `s.upper()`, `s.strip()` (убрать пробелы по краям), `s.replace("а", "о")`, `s.split()` (разбить на список слов), `" ".join(список)`, `s.count("а")`.

Списки (меняют сам список):
`append(x)` — в конец, `insert(i, x)`, `remove(x)` — по значению, `pop(i)` — по индексу и вернуть, `sort()`, `reverse()`, `index(x)`, `count(x)`.
Функции: `len()`, `sum()`, `min()`, `max()`, `sorted()`.

Словари: `d.keys()`, `d.values()`, `d.items()`, `d.get("key", по_умолчанию)` (не падает, если ключа нет), `del d["key"]`.

Множества: `add(x)`, `remove(x)`, `a | b` (объединение), `a & b` (пересечение), `a - b` (разность).

## Тема 2. Ввод и вывод

- `print(...)` — вывод. Можно через запятую: `print("Сумма:", 5)`.
- `input("текст")` — ввод; программа ждёт, пока пользователь не нажмёт Enter.

**Главное:** `input()` **всегда возвращает строку**. Для чисел преобразуй:

```python
a = input("Число: ")        # "5"  (строка)
print(a + a)                # "55" — строки склеиваются
n = int(input("Число: "))   # 5   (число)
print(n + n)                # 10
```

`+` у списков тоже склеивает: `[1, 2] + ["Алиса"]` → `[1, 2, 'Алиса']`.

**f-строки [дописано]** — самый удобный способ вставить переменные в текст:

```python
name, age = "Mat", 19
print(f"Меня зовут {name}, мне {age} лет")
print(f"{10 / 3:.2f}")   # 3.33 — два знака после точки
```

## Тема 3. Операторы

Оператор — символ или слово, которое выполняет действие над значениями (операндами).

### 3.1 Арифметические

| Оператор | Действие | `7 ? 2` |
|---|---|---|
| `+` | сложение | 9 |
| `-` | вычитание | 5 |
| `*` | умножение | 14 |
| `/` | деление (всегда `float`) | 3.5 |
| `//` | целочисленное деление | 3 |
| `%` | остаток от деления | 1 |
| `**` | степень | 49 |

Важные приёмы: `n % 2 == 0` — чётное; `n % k == 0` — `n` делится на `k`; `n % 10` — последняя цифра; `n // 10` — число без последней цифры.

### 3.2 Сравнения → результат `bool`

`==` равно, `!=` не равно, `>`, `<`, `>=`, `<=`. Не путай `=` (присвоить) и `==` (сравнить).

### 3.3 Присваивания

`=`, а также сокращения: `x += 5` это `x = x + 5`; так же `-=`, `*=`, `/=`, `//=`, `%=`, `**=`.

### 3.4 Логические

- `and` — `True`, если **оба** `True`
- `or` — `True`, если **хотя бы один** `True`
- `not` — инверсия

Частая ошибка: `if name == "Aboba" or "Boba"` — **всегда True**, потому что `"Boba"` сам по себе истинен. Правильно: `name == "Aboba" or name == "Boba"` или `name in ("Aboba", "Boba")`.

### 3.5 Принадлежности

`in` / `not in` — есть ли элемент в строке, списке, кортеже, множестве (у словаря — среди ключей).

```python
"а" in "Банан"        # True
3 in [1, 2, 3]        # True
"age" in student      # True — проверка ключа
```

## Тема 4. Условия

```python
if условие:
    ...        # выполняется, если условие True
elif другое_условие:
    ...        # сколько угодно elif, необязательны
else:
    ...        # если ничего выше не сработало, без условия
```

Правила:
- после условия — двоеточие `:`, тело — с отступом 4 пробела;
- в цепочке `if/elif/else` выполняется **только первая** подходящая ветка;
- несколько отдельных `if` подряд — это **независимые** проверки, сработать могут все;
- условия можно вкладывать друг в друга.

```python
age = 17
if age >= 18:
    print("Взрослый")
elif age >= 14:
    print("Подросток")
else:
    print("Ребёнок")
```

Совет: в цепочке ставь условия от частного к общему, иначе ветка может стать недостижимой.

## Тема 5. Циклы

### 5.1 `for` — перебор

Лучше, когда количество повторов известно или надо пройти по коллекции.

```python
for fruit in ["яблоки", "банан"]:
    print(fruit)

for ch in "привет":   # строка перебирается по символам
    print(ch)
```

Число перебрать нельзя (`for i in 25` → ошибка), но можно его строку: `for d in str(25)`.

### 5.2 `range(start, stop, step)`

Генерирует числа; `stop` **не включается**.

```python
range(5)          # 0 1 2 3 4
range(1, 6)       # 1 2 3 4 5
range(10, 0, -2)  # 10 8 6 4 2
```

Перебор с индексом: `for i, item in enumerate(список):` **[дописано]**.

### 5.3 `while` — пока условие истинно [дописано подробнее]

Используется, когда заранее неизвестно, сколько будет повторов.

```python
n = 5
while n > 0:
    print(n)
    n -= 1          # без изменения условия цикл будет вечным
```

Пример — ввод до правильного ответа:

```python
password = ""
while password != "1234":
    password = input("Пароль: ")
print("Вход выполнен")
```

### 5.4 `break` и `continue`

- `break` — немедленно выйти из цикла;
- `continue` — пропустить остаток текущей итерации и перейти к следующей.

```python
for i in range(10):
    if i == 3:
        continue   # 3 пропустим
    if i == 6:
        break      # на 6 выйдем
    print(i)       # 0 1 2 4 5
```

### 5.5 Шаблоны, которые встречаются постоянно

```python
# счётчик
count = 0
for x in data:
    if условие:
        count += 1

# сумма
total = 0
for x in data:
    total += x

# фильтрация в новый список
result = []
for word in words:
    if len(word) >= 5:
        result.append(word)
```

## Тема 6. Классические алгоритмы

Это задачи с пар 24.09 и 29.09 — разобраны и упрощены.

**Делители N.** `i` — делитель, если `N % i == 0` (то же, что ваше `N // i * i == N`, только короче).

```python
N = 12
count = 0
for i in range(1, N + 1):
    if N % i == 0:
        print(i)
        count += 1
print("Количество:", count)
```

**Простое число** — делится только на 1 и на себя (ровно 2 делителя). Быстрее проверять делители только до √N:

```python
N = 29
is_prime = N > 1
for i in range(2, int(N ** 0.5) + 1):
    if N % i == 0:
        is_prime = False
        break
print("Простое" if is_prime else "Составное")
```

**НОД (алгоритм Евклида).** В конспекте вариант с вычитанием и `range(1000)` — на больших числах он не успеет. Правильно через `while` и остаток:

```python
a, b = 48, 18
while b != 0:
    a, b = b, a % b
print("НОД:", a)   # 6
```

**Фибоначчи** — каждое число равно сумме двух предыдущих: 0 1 1 2 3 5 8…

```python
N = 7
a, b = 0, 1
for _ in range(N):
    print(a)
    a, b = b, a + b    # одновременное присваивание, без лишней c
```

**Палиндром** — читается одинаково в обе стороны.

```python
phrase = "А роза упала на лапу Азора"
clean = phrase.lower().replace(" ", "")
if clean == clean[::-1]:
    print("Это палиндром")
else:
    print("Это не палиндром")
```

## Тема 7. Функции

**Функция** — именованный блок кода, выполняющий конкретную задачу. Объявляем один раз, вызываем сколько угодно. Зачем: не повторять код и дать логике понятное имя.

```python
def say_hello():
    print("привет")

say_hello()    # вызов — со скобками
```

### 7.1 `return` против `print`

- `return` **возвращает** значение — его можно сохранить, сложить, передать дальше. После `return` функция сразу завершается.
- `print` только **показывает** на экране; функция без `return` возвращает `None`.

```python
def summ(a, b):
    return a + b

x = summ(5, 7) * 2   # 24 — работает
```

### 7.2 Виды аргументов

```python
def greet():                   # без аргументов
def summ(a, b):                # позиционные — порядок важен
summ(b=3, a=6)                 # именованные — порядок не важен
def power(x, n=2):             # по умолчанию; идут ПОСЛЕ обычных
def total(*nums):              # *args — любое кол-во позиционных → tuple
def info(**data):              # **kwargs — любое кол-во именованных → dict
```

```python
def total(*nums):
    return sum(nums)
total(1, 2, 3)                       # 6

def store(**item):
    return item
store(name="яблоко", price=100)      # {'name': 'яблоко', 'price': 100}
```

Порядок в объявлении: обычные → по умолчанию → `*args` → `**kwargs`.

### 7.3 Области видимости

- **Локальная** — переменная создана внутри функции и снаружи не существует.
- **Глобальная** — создана вне функций, читать её внутри можно.
- `global имя` — разрешает **изменить** глобальную переменную изнутри функции. Пользоваться редко: лучше передать значение аргументом и вернуть через `return`.

```python
count = 100

def show():
    global count
    count = 8

show()
print(count)   # 8
```

### 7.4 Рекурсия

Функция вызывает саму себя. Обязательно нужен **базовый случай** — условие остановки, иначе ошибка `RecursionError` (по умолчанию лимит ~1000 вызовов).

```python
def factorial(n):
    if n <= 1:          # базовый случай
        return 1
    return n * factorial(n - 1)

factorial(5)   # 120
```

Как думать: «ответ для n = что-то + ответ для n-1», а для самого маленького n ответ известен сразу.

## Тема 8. Ошибки, которые были в конспекте

Стоит знать, чтобы не повторять:

1. **Палиндром:** перевёрнутую строку сравнивали с исходной фразой (с пробелами и заглавными) — всегда выйдет «не палиндром». Сравнивать нужно с очищенной строкой.
2. **`("привет")`** — не кортеж, а строка. Кортеж из одного элемента: `("привет",)`.
3. **Деление на ноль в калькуляторе:** после `print("ошибка")` функция всё равно делит и падает. Нужно `return` сразу: `if num2 == 0: return "ошибка"`.
4. **Имена `list`, `dict`, `sum` для своих переменных/функций** — затирают встроенные функции Python. После `def sum(...)` встроенный `sum()` перестаёт работать. Называй `my_list`, `add` и т.п.
5. **«Любой int по умолчанию является str»** — неточно. Строку возвращает именно `input()`, сам `int` остаётся числом.
6. **НОД через `range(1000)`** — на больших числах может не досчитать. Используй `while`.
7. **Ветка `elif number2 < number1`** в примере никогда не сработает: случай `number1 > number2` уже перехвачен первым `if`.
8. **`print("name")`** печатает слово name, а не переменную — кавычки делают строку.
