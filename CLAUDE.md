# Python-учебник: презентация + задания

## Суть
Сайт для самостоятельного изучения основ Python. По каждой теме сначала идёт интерактивная презентация (слайды с теорией и живыми примерами кода), а сразу после неё — задания по этой теме, которые решаются прямо в браузере. Пользователь один: студент, готовится по конспекту колледжа.

## Контент — источник правды
- `content/01_teoriya_python.md` — теория. Тема = `## Тема N. Название`, слайд = каждый `### подраздел` (если подразделов нет — тема режется на слайды по смысловым блокам ~ на экран).
- `content/02_zadaniya_python.md` — задания `**N.M 🟢/🟡/🔴** текст` в разделе темы, решения — в конце файла под `### N.M`.
- Контент НЕ копировать в код вручную. Парсить md при сборке (или при загрузке) — чтобы правка md сразу меняла сайт.
- Тема 8 (ошибки конспекта) — только слайды, без заданий. Это нормально.

## Функции (ядро, только это)
1. Презентация темы: слайды, стрелки ←/→ и клавиатура, прогресс «слайд 3 / 9».
2. Каждый пример кода на слайде — с кнопкой «▶ Запустить» и выводом под ним.
3. После последнего слайда темы — экран заданий этой темы: редактор кода, «Запустить», вывод/ошибка, «Показать решение» (раскрывается, можно загрузить в редактор), «Отметить решённым».
4. Сохранение прогресса: на каком слайде остановился, код в каждом задании, отметки решённых.
5. Главная: список тем с прогрессом (слайды пройдены / задания решены), продолжить с того места.

## Отложено (не делать в v1)
Автопроверка ответов тестами, аккаунты, темы ООП и библиотек, геймификация, мобильное приложение.

## Экраны и навигация
- Главная → карточки тем → Тема.
- Тема: режим «Теория» (слайды) → кнопка «К заданиям» на последнем слайде → режим «Задания» → «Следующая тема».
- В шапке темы переключатель Теория/Задания, чтобы вернуться к слайдам.
- Роутинг по hash (`#/topic/3/slides/2`), чтобы ссылка открывала нужное место.

## Данные
- Всё локально: localStorage. Без бэкенда, без входа.
- Оффлайн: после первой загрузки Pyodide желательно кешировать (не критично для v1).

## Техника
- Vite + React + TypeScript. Без UI-фреймворков, свой CSS.
- Python в браузере: Pyodide (официальный CDN, закрепить точную версию). Загружать один раз, лениво — при первом нажатии «Запустить», с индикатором «Загружаю Python…» (~10 МБ).
- Запуск кода в Web Worker, чтобы вечный `while True` не вешал страницу; кнопка «Стоп» (перезапуск воркера) и таймаут ~5 сек.
- `print` → перехват stdout/stderr в панель вывода. Ошибки показывать понятным текстом + строка.
- `input()`: во многих заданиях он есть. Решение: над редактором поле «Ввод (каждое значение с новой строки)», `input()` читает оттуда построчно; если строки кончились — понятная ошибка «не хватает ввода». Вывести текст подсказки `input("...")` в вывод, как в терминале.
- Редактор: CodeMirror 6 с подсветкой Python, Tab = 4 пробела.
- Markdown: `marked` или `markdown-it`; подсветка кода в слайдах той же темой, что в редакторе.
- Адаптив: сначала мобильная вёрстка, на телефоне слайды листаются свайпом.

## Дизайн
- Тёплый и мягкий: кремовый/тёплый светлый фон, мягкие тени, скругления 16–20px, спокойный терракотовый или персиковый акцент.
- Тёмная тема тоже тёплая (тёмно-коричневый, а не чёрно-синий), по системной настройке.
- Шрифт текста — читабельный гротеск (Inter / Manrope), код — JetBrains Mono.
- Анимация перехода слайдов лёгкая (сдвиг + fade, 200–250 мс), уважать `prefers-reduced-motion`.
- Ориентир по ощущению: Duolingo по мягкости, Notion по чистоте текста. Не копировать.

## Не делать
- Не хардкодить тексты тем и заданий в компонентах.
- Не использовать `eval`/свой «псевдо-Python» вместо Pyodide.
- Не грузить Pyodide на главной странице заранее.
- Не тащить тяжёлые библиотеки ради анимаций (без GSAP, Framer Motion можно не брать).
- Не делать бэкенд, авторизацию, аналитику.
- Не переписывать содержимое md (исправлять опечатки — только если спрошу).

## Обязательно
- Никаких заглушек и TODO — каждая функция работает.
- Только реально существующие библиотеки, версии закреплены.
- Состояния: загрузка Python, ошибка загрузки (нет сети) с кнопкой «Повторить», пустой вывод («Программа ничего не вывела»).
- Если формат md не парсится однозначно — спроси, а не придумывай.

## Допущения (решены за пользователя)
- Vite + React + TS: React пригодится в колледже, а сайт маленький.
- Pyodide вместо серверного запуска: бесплатно и без бэкенда; цена — первая загрузка ~10 МБ.
- Ввод через поле, а не через `prompt()`: в воркере `prompt()` недоступен.
